Chrome Extension Permission Audit

Canvid for SkoleTube · reviewed 2 September 2026 · read-only repository audit

Recommended cleanup: remove declarativeNetRequest and keep declarativeNetRequestWithHostAccess. Chrome says they provide the same capability. The extension already has the Google Storage host permissions needed by its static rule, so declaring both is redundant.

What each permission does

One permission can be removed

declarativeNetRequest*

A static rule adds CORS response headers to requests for storage.googleapis.com. It is limited to XMLHttpRequest and other resource types.

Call site: manifest static ruleset → chrome-ext/rules/gcs-cors.json

Used to add CORS response headers only to Google Cloud Storage requests required for Canvid media uploads and downloads.
Used

scripting

Runs a Google Cloud Storage download in the main world of an existing Canvid web-app tab when extension-origin requests are blocked by bucket CORS.

Call site: src/lib/extension-cross-origin-put.ts:175

Used to execute a Google Cloud Storage download from the Canvid web application context when extension-origin requests are blocked by CORS. Scripts are injected only into Canvid application pages.
Used

unlimitedStorage

Supports the extension's Origin Private File System storage for projects, recordings, media, and avatars. The app also requests persistent storage through navigator.storage.persist().

Call site: src/bridge-shim.ts:90

Canvid stores video projects, recordings, media, and generated assets locally using the Origin Private File System. These files can exceed normal browser storage quotas and must be protected from automatic eviction.
Used

webRequest

Observes completion status codes for Google Cloud Storage PUT requests when CORS hides an otherwise successful upload response. It does not inspect request bodies or modify traffic.

Call site: chrome-ext/background.js:200

Used only to observe completion status codes for uploads to Google Cloud Storage. This lets Canvid distinguish successful and resumable uploads when CORS prevents the extension from reading the response. Request bodies and browsing activity are not inspected.
