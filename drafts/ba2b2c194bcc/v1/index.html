One app, two installs. The PWA owns the UI and media. The companion runs Chrome APIs the PWA cannot call directly.

Hosted PWA

UI, recording, media

React app, Web APIs, Origin Private File System. Installed from HTTPS, or opened on loopback in development.

Installed companion

Privileged Chrome calls

desktopCapture, system, and windows. Loaded unpacked in development, distributed as an extension in production.

1. The boundary that matters

Before

Assumes an extension page

  1. 1recording.start()
  2. 2chrome.windows.getCurrent()
  3. 3chrome.windows.update(...)

Fails in a PWA: chrome.windows is absent.

After

Route privileged work

  1. 1recording.start()
  2. 2minimizeCurrentChromeWindow()
  3. 3PWA → companion message
  4. 4companion → sender window
  5. 5extension page → direct API

Existing full-extension behavior is retained.

2. Startup is a gate, not discovery

The PWA must already know the extension ID. Loading an extension alone does not tell the page which extension to call.

Both sides must agree
